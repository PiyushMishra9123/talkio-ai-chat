# 🤖 Talkio AI Chat

Talkio is a full-stack **AI Chat Assistant** built with **React.js and Node.js**. It provides an interactive chat experience with AI-powered responses along with voice support, chat history, dark mode, and Cloudflare Workers AI integration.

> 🚀 A modern AI chat application designed for a smooth and interactive user experience.

---

## ✨ Features

* 🤖 **AI-Powered Chat**

  * Chat with an AI assistant through an interactive interface.
  * Get AI-generated responses to user queries.

* 🎤 **Voice Support**

  * Listen to AI responses using voice interaction.
  * Provides a more natural way to interact with the assistant.

* 💬 **Chat History**

  * Maintains previous conversations.
  * Makes it easier to continue or review conversations.

* 🌙 **Dark Mode**

  * Toggle between light and dark themes.
  * Provides a comfortable experience in different environments.

* ⚡ **Cloudflare Workers AI Integration**

  * Uses Cloudflare Workers AI for AI-powered functionality.

* 📱 **Responsive Interface**

  * Designed to provide a smooth experience across different screen sizes.

## 🔄 How It Works

1. The user enters a message through the React.js frontend.
2. The frontend sends the request to the backend.
3. The backend processes the request and handles communication with the AI service.
4. Cloudflare Workers AI is used for AI-powered responses.
5. The response is returned to the frontend and displayed to the user.
6. Voice support allows users to listen to the generated response.
7. Chat history helps users access previous conversations.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/PiyushMishra9123/talkio-ai-chat.git
```

### 2. Navigate to the Project

```bash
cd talkio-ai-chat
```

### 3. Setup Backend

```bash
cd Backend
npm install
```

Create a `.env` file inside the backend directory and add the environment variables required by your backend configuration.

Then start the backend using the command configured in `package.json`.

### 4. Setup Frontend

Open another terminal:

```bash
cd FRONTEND
npm install
```

Start the React development server:

```bash
npm run dev
```

## 🔐 Environment Variables
